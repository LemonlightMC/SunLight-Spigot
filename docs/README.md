# SunLight Wiki

**SunLight** is a modern, lightweight, all-in-one core plugin for Minecraft servers. It provides essential server management tools through **31 fully optional modules**, so you can enable only what your server actually needs.

## Highlights

- **Modular design** — toggle features on or off in `modules.yml`
- **SQLite & MySQL** support for persistent data
- **Highly customizable** — commands, GUIs, messages, and module settings can be tailored to your server
- **Offline player support** — many actions work even when the target player is offline
- **MiniMessage & PlaceholderAPI** support in many places
- **Command cooldowns and costs** — configurable per command/provider

## What is included

SunLight ships with modules for moderation (bans, reports, freeze, vanish), communication (chat, socials, links, greetings, texts), teleportation and travel (homes, warps, player warps, spawns, RTP, back/deathback, TPA, warmups), utilities (essential tools, inventories, items-related utilities where available, kits, scheduler, timer), player customization (nametags, glow, nick, settings), and quality-of-life systems (AFK, playtime, friends, profiles, voting, nerf phantoms, death messages, worlds support noted in README).

> **Note:** Module availability and behavior can depend on server version, dependencies, and module-specific load conditions. See [Requirements & Dependencies](getting-started/requirements.md).
